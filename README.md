# Apex Automotive Aesthetics

Crie um website completo, moderno e premium para uma empresa especializada em ESTÉTICA AUTOMOTIVA PREMIUM.

O objetivo é criar uma experiência visual extremamente sofisticada, agressiva e cinematográfica, inspirada em websites de marcas automotivas premium, empresas de detailing, preparação estética e performance.

IMPORTANTE:

Não copie literalmente nenhum dos layouts ou elementos das imagens de referência.

Use as imagens anexadas APENAS como referência visual para:

- direção artística

- composição

- hierarquia

- contraste

- atmosfera

- tratamento de imagens

- tipografia

- uso de espaços

- animações

- sensação premium

O resultado deve parecer um website original de uma marca de estética automotiva de alto padrão.
